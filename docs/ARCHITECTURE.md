## 1. Maqsad

EduTrack — kollej / texnikum boshqaruv tizimi. Loyiha hozir **test bosqichida** (SQLite, lokal). Frontend va backend bitta papkada aralash turgan, build artifactlari va test DB git ga commit qilingan, `.sln` faylida qo'sh kengaytma bor edi. 1-bosqich maqsadi: tuzilmani toza, deploy va CI uchun qulay holatga keltirish.

## 2. 1-bosqichda qilingan ishlar

### 2.1. Frontend va backend ajratildi

Avval frontend (`ClientApp/`) backend ichida joylashgan edi (`EduTrack/EduTrack/ClientApp/`). Endi:

- `EduTrack/ClientApp/` → **`frontend/`** (repo root ga ko'chirildi)
- `EduTrack/` (Web API) → **`backend/EduTrack/`**
- `EduTrackDataAccess/` → **`backend/EduTrackDataAccess/`**

Barcha ko'chirishlar `git mv` orqali qilindi — git tarixi saqlanib qoldi (160 ta rename git tomonidan tan olindi).

### 2.2. Solution fayli tuzatildi

- `EduTrack.sln.sln` (qo'sh kengaytma) → `backend/EduTrack.sln`
- `.sln` ichidagi project pathlar: o'zgarmadi (chunki `.sln` va ikkala `.csproj` birga ko'chirildi).
- `EduTrack.csproj` dagi `<ProjectReference Include="..\EduTrackDataAccess\..." />`: o'zgarmadi (relative path saqlanib qoldi).
- ✅ `dotnet restore backend/EduTrack.sln` muvaffaqiyatli.
- ✅ `dotnet sln EduTrack.sln list` ikkala loyihani topdi.

### 2.3. Yakka fayllar tartiblandi

- `GenHash.cs` (root da yotgan parol hash utility) → `backend/tools/GenHash.cs`
- `package-lock.json` (root da, 93-baytlik orphan stub) — o'chirildi
- `EduTrack.sln.sln` — qayta nomlandi (`.sln`)

### 2.4. Git tozalanish

## 4. Texnologiya stacki

### Backend
- **.NET 8** (`net8.0`)
- **Entity Framework Core 8** (`Microsoft.EntityFrameworkCore.Sqlite`)
- **SQLite** (test bosqichi — keyingi bosqichda PostgreSQL ga o'tkaziladi)
- **JWT Bearer** (`Microsoft.AspNetCore.Authentication.JwtBearer 8.0.0`)
- **BCrypt.Net-Next** parol hash uchun
- **Swashbuckle / Swagger** API hujjatlari uchun
- **Pattern:** Repository + Service layer + Controller

### Frontend
- **Angular 21** (standalone components, signals, zoneless)
- **Angular Material 21**
- **TypeScript 5.9**
- **Tailwind CSS 3.4**
- **ngx-quill** (rich text editor)
- **sweetalert2** (modal/dialog)
- **State:** Angular signals (`signal()`, `computed()`, `effect()`)
- **HTTP:** Functional interceptors (`apiInterceptor`, `errorInterceptor`)
- **Routing:** Lazy-loaded standalone routes + `CanActivateFn` guards

## 6. Run / test

### Backend
```powershell
cd backend
dotnet run --project EduTrack
```
- Swagger: `https://localhost:7001/` (root path)
- API base: `/api/...`
- Birinchi run da EF avtomatik migrate qiladi va `edutrack.db` yaratadi.

### Frontend
```powershell
cd frontend
npm install
npm start
```
- Dev server: `http://localhost:7010`
- API ga `environment.development.ts` orqali ulanadi (`https://localhost:7001/api`).

### Solution build
```powershell
cd backend
dotnet build EduTrack.sln
```
> ⚠️ **Eslatma:** Joriy mashinada .NET 10.0.201 SDK Roslyn'i Windows CET muammosi sababli build da fatal error berishi mumkin. `dotnet restore` muvaffaqiyatli ishladi — bu paths to'g'ri ekanini tasdiqlaydi. Build muammosi hal qilish uchun: Windows yangilash yoki `global.json` orqali .NET 8 SDK ni majburlash.

## 8. Keyingi bosqichlar (rejada)

### 2-bosqich — hujjatlarni yangilash
- `BACKEND_AI_INSTRUCTIONS.md` ni yangi tuzilma + SQLite + real entitilar (Employee/Profession/News) ga moslab yangilash, `docs/BACKEND.md` ga ko'chirish.
- `FRONTEND_AI_INSTRUCTIONS.md` ni `docs/FRONTEND.md` ga ko'chirish.
- `deployment.txt` ni `docs/DEPLOYMENT.md` ga aylantirish (markdown sintaksisi bilan).
- Repo root ga `README.md` yozish (loyiha haqida birinchi tanishtirish).

### 3-bosqich — kod sifati
- `Models/Dtos.cs` ni alohida fayllarga bo'lish (`Models/Auth/`, `Models/Assignments/` ...).
- Controller'larga `[Authorize(Roles = "...")]` qo'shish.
- DTO'larga validation atributlari (`[Required]`, `[MaxLength]`).
- `IUserReporitory` typo'sini tuzatish (`IUserRepository`).
- `EduTrackDataAccess.csproj` dagi keraksiz `<Folder Include="Migrations\" />` ni olib tashlash.

### 4-bosqich — PostgreSQL ga o'tkazish
- `Npgsql.EntityFrameworkCore.PostgreSQL` paketini qo'shish.
- `Program.cs` da `UseSqlite` → `UseNpgsql`.
- Connection string ni `appsettings.json` ga ko'chirish.
- Yangi PostgreSQL migration yaratish (eski SQLite migration'larni saqlab qoldirish yoki tozalash).
- Local dev uchun `docker-compose.yml` (Postgres konteyneri).
